# Adaptive V1 Improvement Backlog

This is a planning record, not implementation authorization. Every direction below must be evaluated against `adaptive-agent-v1-baseline` using the version comparison contract. No item authorizes a case-specific exception.

| ID / module | Observed problem | Evidence / affected cases | Likely root cause | Generalizable proposed direction | Expected metric | Overfitting risk | Priority |
|---|---|---|---|---|---|---|---|
| BL-01 / Input Understanding | Explicit facts are dropped across language variants, including Chinese numeral/duration and compound statements. | AF-IU-001/002/003; CA-02, PD-01, PD-02, PD-03. | Narrow deterministic patterns do not cover all explicit Chinese expressions; structured output is then conservatively discarded. | Extend fact extraction as a provenance-preserving semantic normalization layer that recognizes equivalent duration, clock, count and compound-clause forms across fields. | Explicit-fact recall; fact-level precision; redundant ASK / case. | High if rules memorize only benchmark wording; require held-out language variants. | P0 |
| BL-02 / State Integrity | A compound sentence can be stored under one field while another explicit field is absent. | AF-SI-004; PD-03 across Steps 5.1, 5.3, 5.5. | Normalization does not enforce independent slots/provenance for every supported fact span. | Validate each fact slot independently against source spans; preserve multiple non-overlapping facts from one utterance and reject ambiguous field ownership. | Field-level provenance completeness; compound-fact split recall; fabricated/unsupported fact rate. | High if optimized only for caffeine/night-awakening wording; require diverse multi-fact utterances. | P0 |
| BL-03 / Answer Grounding | A final answer may use raw-language knowledge that did not enter current State. | AF-AG-005; PD-03 in Steps 5.1 and 5.3. | Prompt/post-processing constrains quantities but lacks a complete claim-to-fact provenance check for non-quantitative user-specific claims. | Add a general claim-provenance gate: user-specific statements must map to a current State fact source; otherwise remove or restate as unknown. | Critical grounding failures; unsupported user-specific claim rate; answer-scope compliance. | Medium; must avoid suppressing legitimate evidence-grounded general explanations. | P0 |
| BL-04 / Sufficiency | No confirmed system-level defect is isolated after separating upstream extraction omissions; changing sufficiency now would confound attribution. | Step 5.4/5.5: CA/PD degraded paths are primarily Input Understanding failures. | Not established. | Hold behavior frozen; add ablation/trace assertions that distinguish missing-State inputs from sufficiency errors before proposing a change. | Independent sufficiency-failure count, not overall score alone. | High if changed to reduce ASK merely on current ten cases. | P2 |
| BL-05 / Candidate Generation | No independently demonstrated candidate-generation defect; candidate quality is downstream of missing facts in known failures. | Step 5.4/5.5 ASK attribution. | Not established. | Preserve V1 candidate logic; instrument candidate availability/rationale in future runs before considering changes. | Candidate-to-selected-action audit coverage. | High if retuned against a fixed ASK order. | P2 |
| BL-06 / Policy | No evidence supports treating the current four redundant asks as Policy failures. | Step 5.4/5.5; same candidates are built from incomplete State. | Upstream State integrity, not proven policy defect. | Do not change Policy until a trace shows a redundant ASK when the explicit fact already exists in State. | Policy-independent redundant-ASK count. | High if a blanket ASK suppression reduces safety. | P2 |
| BL-07 / Tool Execution | Full-system diary superiority is not a policy-only conclusion; Fixed lacks `READ_DIARY`, and component tool timing is absent. | DA-01/DA-02; Step 5.5 confounds. | Capability asymmetry and incomplete observability. | Keep resource capability separate from decision claims; add non-behavioral timing/call instrumentation around stable tool interfaces. | Resource-contract pass rate; measured retrieval/tool latency coverage. | Low for instrumentation; high if fixtures are injected outside tool interfaces. | P1 |
